# Changelog

## 1.1.0 - 2026-11-24
- New Trippy Tunnel style (default): mirrored kaleidoscope rings, spinning spokes, bass orb and beat flashes
- Proper music sync: dB-scaled spectrum with auto-gain, so bars use the full range on quiet and loud tracks
- Beat detection now uses bass spectral flux with an adaptive threshold, with a smooth beat pulse shared by all styles
- Now Playing: track title and artist from Music and Spotify, controls work and stay visible while paused
- 8 new colour themes: Rainbow, Aurora, Lava, Vaporwave, Toxic, Rose Gold, Deep Space, Synthwave
- Controls hide when the main window is full screen
- Fixed menu bar bars and other styles to use the new scaling

## 1.0.0 - 2026-07-09
- Mic and system audio input with FFT spectrum
- Styles: Spectrum Bars, Mirror Bars, Radial Pulse, Waveform Ribbon, Dot Grid
- 12 colour themes, selected separately for the app and menu bar
- Menu bar visualizer (Compact and Wide) and full screen mode (Cmd+F, Esc to exit)
- Now Playing controls
- CPU reductions for long sessions
